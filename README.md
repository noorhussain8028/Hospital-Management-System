
# Hospital Management System

A beginner-friendly Hospital Management System developed using Java and Object-Oriented Programming (OOP).

## Features

- Add Patients
- View Patients
- View Doctors
- Book Appointments
- View Appointments
- Check Doctor Availability

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- IntelliJ IDEA

## OOP Concepts

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Object Relationships

## Project Structure

    HospitalManagementSystem/
    └── src/
        └── hospitalmanagementsystem/
            ├── Main.java
            ├── Patient.java
            ├── Doctor.java
            └── Appointment.java

## How to Run

1. Download or clone the repository.
2. Open the project in IntelliJ IDEA.
3. Install Java JDK.
4. Run Main.java.

## Note

- No SQL or database is used.
- Data is stored temporarily using ArrayList.
- Data will be lost when the program closes.

## Purpose

Created as a beginner Java project to practice OOP concepts.

**Developed using Java.**
